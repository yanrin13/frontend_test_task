# To-Do App

## Запуск проекта

1. Клонировать репозиторий:

```bash
git clone https://github.com/yanrin13/frontend_test_task.git
```

2. Перейти в папку проекта:

```bash
cd frontend_test_task
```

3. Установить зависимости:

```bash
npm install
```


4. Запустить проект в режиме разработки:

```bash
npm run dev
```
или
```bash
npm run dev -- --host 0.0.0.0   
```

5. Открыть адрес из терминала (дефолтное значение: `http://localhost:5173`).


Примерное время выполнения задания: **40 минут**
